English
===============================================

Internationalize your game by adding this language manager.
        
You will be able to create new languages ​​and delete them, create, edit and delete translations.
        
Content:
- Administrator in windowed mode for greater ease, accessing from the menu or pressing CTRL + SHIFT + L.
- Fully integrated with TextMesh PRO.
- Custom components with TextMesh PRO in the menus for greater comfort.
- You can export the main language to the JSON format, useful if you have to send it to an external entity to translate it and then import it.
- Import and use without complications.
        
It also includes the management of preferences in '.ini' files. See the Settings.cs class (located in 'Assets \ BundleLanguageManagerPack \ OlivaDevelop \ Utils \ Configuration \ Settings.cs') and replace the text 'yourSettingsFile' with a valid name to store your settings.
        
You can integrate it to make a dynamic language change in your game. In the ConfigKeys.cs class ('Assets \ BundleLanguageManagerPack \ OlivaDevelop \ Utils \ Configuration \ ConfigKeys.cs') there is a list of keys to store your preferences that you can configure to your liking. For language management, 'ConfigKeys.Language' is used.



Español
===============================================

Internacionalice su juego agregando este administrador de idiomas.

Podrá crear nuevos idiomas y eliminarlos, crear, editar y eliminar traducciones.

Contenido:
- Administrador en modo ventana para mayor facilidad, accediendo desde el menú o presionando CTRL + MAYÚS + L.
- Totalmente integrado con TextMesh PRO.
- Componentes personalizados con TextMesh PRO en los menús para mayor comodidad.
- Puede exportar el idioma principal al formato JSON, útil si tiene que enviarlo a una entidad externa para traducirlo y luego importarlo.
- Importación y uso sin complicaciones.

Además incluye la gestión de preferencias en ficheros '.ini'. Vea la clase Settings.cs (ubicada en 'Assets\BundleLanguageManagerPack\OlivaDevelop\Utils\Configuration\Settings.cs') y reemplace el texto 'yourSettingsFile' por un nombre válido para almacenar su configuración.

Podrá integrarlo para realizar un cambio dinámico de lenguaje en su juego. En la clase ConfigKeys.cs ('Assets\BundleLanguageManagerPack\OlivaDevelop\Utils\Configuration\ConfigKeys.cs') hay un listado de claves para almacenar sus pereferencias que puede configurarlo a su gusto. Para la gestión del idioma se usa 'ConfigKeys.Language'.
